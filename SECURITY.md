# Security policy

This is experimental local native software. Do not use it with untrusted clients
or expose its pipe/endpoint files through a network service. There is no remote
editing server and no account/password system.

For vulnerabilities, use GitHub's **Report a vulnerability** / private advisory
channel if enabled. If unavailable, open an issue requesting a private contact
without exploit details. Do not post tokens, endpoint files, private maps, full
session snapshots or personal paths. Ordinary reproducible bugs belong in issues.

The alpha has no guaranteed security support window. See docs/SAFETY.md for the
known save notification and recovery limitations.
